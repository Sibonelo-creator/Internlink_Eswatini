INTERNLINK — HTML DEMONSTRATION WEBSITE

HOW TO RUN
1. Extract the ZIP file.
2. Open the InternLink-Website folder.
3. Double-click index.html. Internet is needed for Lucide icons and rotating Unsplash photos.

DEMONSTRATION FLOW
1. Create an Intern account. After registration, the form switches to Login.
2. Log in using the exact same email and password. Passwords are case-sensitive.
3. Choose an opportunity and select Apply with documents.
4. Attach CV, application letter, letter from school and academic transcript. PDF, DOC and DOCX are accepted, up to 700 KB each. You can replace a selected file before submitting.
5. Log out. Create an Organisation account in the same browser and log in.
6. Publish an opportunity from the organisation dashboard, or review applications to any listing owned by that organisation.
7. Each application is shown separately with applicant details, note and four individual document links. Update the decision to Submitted, Shortlisted, Accepted or Rejected.

IMPORTANT DEMONSTRATION LIMITATION
This is a browser-only HTML/CSS/JavaScript demonstration. Accounts, passwords, jobs, applications and attached file data are stored locally in this browser (localStorage). Attachments are retained as browser data and can be opened/downloaded from the organisation view on the same browser/device. Nothing is transmitted to an actual organisation, server, database, email address or another device. Browser data can be cleared by clearing site data. Use demonstration accounts and sample documents only.

TECHNOLOGY
HTML5, CSS3 and JavaScript; Lucide icons loaded from CDN; rotating Unsplash image carousel. No PHP and no database.
